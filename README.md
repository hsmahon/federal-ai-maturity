# Federal AI Maturity

Federal AI Maturity is a static view of the [OMB 2025 Federal Agency AI Use Case Inventory](https://github.com/ombegov/2025-Federal-Agency-AI-Use-Case-Inventory), organized around agency footprint and operational maturity.

Inspired by [Karpathy's jobs board](https://github.com/karpathy/jobs), the project aims for a dense, visual-first interface where the main canvas carries most of the story.

Live site: [hsmahon.github.io/federal-ai-maturity](https://hsmahon.github.io/federal-ai-maturity/)
